# RESET 2.0

## Upload to your GitHub repository
Upload `index.html`, `manifest.json`, `sw.js`, and `icon.svg` into the root of `RESET-REBUILD-`, then commit to `main`.

## Publish with GitHub Pages
Open repository **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save.

After deployment, the site should be at:
https://chrislefoka-boop.github.io/RESET-REBUILD-/

## Install on Android
Open the published site in Chrome, open the menu, and choose **Install app** or **Add to Home screen**. The manifest provides the RESET icon and standalone display setting. Android launcher behaviour can vary.

## Privacy
Notes are stored in browser local storage on this device. Clearing browser data may remove them. This tool is not a replacement for professional support.
